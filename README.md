# soop-vote-helper

SOOP 투표 도우미입니다.

다수의 SOOP 방송 채팅 메시지를 읽어 투표를 집계하는 Electron 데스크톱 앱입니다.

OBS, 프릭샷 등의 브라우저 소스 기능으로 오버레이를 띄울 수도 있습니다.

## 주요 기능

- 여러 SOOP 방송 채팅방 연결
- `!투표 [키]` 형식의 채팅만 투표로 집계
- 아이디당 1표 집계, 중복 투표 시 가장 마지막 투표만 반영 (투표 변경 가능)
- 투표 항목별 이름과 차트 색상 설정
- 최근 투표 채팅, 파이 차트, 막대 차트, 순위, 시간대별 추이 표시
- 각 결과 화면을 브라우저 소스용 오버레이 URL로 복사

### 환경 변수

개발 모드에서는 Vite 개발 서버가 Electron 내부 API 서버로 `/api` 요청을 프록시합니다. `.env`에 API 서버 포트를 지정합니다.

```env
VITE_API_PORT=3000
```

## 사용 방법

1. `설정` 탭을 엽니다.
2. `SOOP ID 연결`에 채팅을 읽을 스트리머의 SOOP ID를 추가하고 재생 버튼을 눌러 연결합니다.
3. `투표 항목`에 투표 키, 항목명, 차트 컬러를 등록합니다.
   - 예: 키가 `1`, 항목명이 `A팀`이면 시청자는 `!투표 1`로 투표합니다.
4. `집계 시작`을 누르면 연결된 채팅방의 채팅을 읽어 투표 집계가 시작됩니다.
5. `투표` 탭에서 실시간 결과를 확인합니다.
6. `오버레이` 탭에서 원하는 화면에 마우스를 올리고 URL을 복사해 OBS 또는 프릭샷의 브라우저 소스에 추가합니다.

### 투표 규칙

- 채팅 메시지는 `!투표 [키]` 형식이어야 합니다.
- 같은 사용자가 여러 채팅방에서 투표해도 하나의 아이디당 한 표만 집계됩니다.
- 같은 사용자가 다시 투표하면 이전 투표는 무효가 되고 마지막 투표만 반영됩니다.
- 등록되지 않은 키로 투표한 채팅은 무효표로 집계에서 제외됩니다.

## 프로젝트 구조

```text
.
├─ electron/            # Electron 메인 프로세스와 Fastify API
├─ public/              # 아이콘 등 정적 자산
├─ src/                 # 화면 UI
│  ├─ components/       # UI 컴포넌트
│  ├─ hooks/            # renderer 훅
│  └─ utils/            # 범용 유틸리티
├─ dist/                # 렌더러 빌드 결과물
├─ dist-electron/       # Electron 빌드 결과물
└─ release/             # 배포 산출물
```
